> **OSINT4Me** is a modern, open-source directory of OSINT (Open Source Intelligence) tools.  
> Browse, search, and discover hundreds of tools categorized for investigators, researchers, and cybersecurity enthusiasts.

---

## ✨ Features

- 📂 **Categorized tools** – Browse by category with collapsible sections
- 🤖 **AI page** – AI tools classified by role (Conversational, Image, Video, Audio, Data Analysis, Code & Dev)
- 🌍 **Multilingual** – English / French support (switch anytime)
- 👁️ **Visitor counter** – Simple tracking with localStorage
- 💡 **Suggest a change** – Propose new tools or report broken links
- 🔧 **Admin panel** – Edit, import, export tools.json on the fly
- 📱 **Fully responsive** – Works on desktop, tablet, and mobile
- 🎨 **Dark theme** – Easy on the eyes for late-night investigations

## 🛠️ How to Use

### For Users
1. Browse tools by category on the **Home** page
2. Explore AI tools on the **AI** page
3. Use the **Suggest** page to propose changes or report issues
4. Switch between **English** and **French** using the top-right switcher

### For Developers / Self-Hosting

```bash
# Clone the repository
git clone https://github.com/matiouh77600/osint4me.git
cd osint4me

# Edit tools.json to add or remove tools
# Open index.html in your browser or deploy to GitHub Pages
